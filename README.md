# home-ai-agent
基于Xiaomi Miloco架构，利用MiMo-VL-7B端侧视觉模型，让普通家庭通过自然语言控制全屋IoT设备。系统能识别"准备睡觉""准备出门"等场景，自动调节灯光、空调、窗帘，实现从"手动配置规则"到"AI主动理解"的升级
本项目正在参与小米MiMo Orbit百万亿Token计划。

## 项目目标
利用MiMo-VL-7B端侧模型，将传统智能家居从“规则触发”升级为“AI推理驱动”

## 核心功能
- [ ] 自然语言理解（“我准备出门了”→自动关灯关空调）
- [ ] 视觉场景识别（摄像头画面识别“小孩在写作业”→开护眼灯）
- [ ] 车家联动（车辆接近家门→自动开锁开灯开空调）

## 技术栈
- MiMo-VL-7B（端侧视觉推理）
- MiMo-V2.5-Pro（长程决策）
- Xiaomi Miloco（家居中间件）
